# HolisticVox

Source files for the HolisticVox website — a bilingual (EN/ES) natural health and wellness site with a curated product marketplace, articles, recipes, and a practitioner directory.

## Structure
- `index.html` — the entire site (single-page app with client-side routing)
- `images/` — all product, article, and recipe photos referenced by `index.html`

## Deployment
This site is a static site — no build step required. It's deployed via Cloudflare Pages, connected directly to this GitHub repository. Any push to the `main` branch triggers an automatic redeploy.
